## 接入参数

埋点接入前向平台方确认三个核心参数（以下示例均为占位符）：

- `sapp_id`：应用 ID（如 `YOUR_SAPP_ID`）
- `sapp_name`：应用标识（如 `YOUR_SAPP_NAME`）
- `bid`：稳定性监控应用标识，通常格式为 `${sapp_name}_zzdpro`（如 `YOUR_BID`）

## SPA 手动采集封装

单页应用切换路由不会刷新文档，需先通过 `aplus-waiting` 设为 `MAN` 关闭自动 PV，再在每次路由切换后显式调用 `aplus.sendPV`。若用户信息异步获取，必须用 `_hold` 的 `BLOCK` / `START` 包裹用户 ID 设置，避免首条 PV 丢失 `_user_id`。

```ts [utils/aplus.ts]
declare global {
  interface Window {
    aplus_queue?: Array<{ action: string, arguments: unknown[] }>
  }
}

const APLUS_CONFIG = {
  sapp_id: 'YOUR_SAPP_ID',
  sapp_name: 'YOUR_SAPP_NAME'
} as const

function pushAplus(action: string, ...args: unknown[]) {
  window.aplus_queue = window.aplus_queue || []
  window.aplus_queue.push({ action, arguments: args })
}

/** 在路由落地后发送一次页面 PV（自定义字段仅支持平铺键值对） */
export function trackPageView(pageId: string, pageName: string, pageUrl: string) {
  pushAplus('aplus.setMetaInfo', 'aplus-waiting', 'MAN')
  pushAplus('aplus.sendPV', { is_auto: false }, {
    sapp_id: APLUS_CONFIG.sapp_id,
    sapp_name: APLUS_CONFIG.sapp_name,
    page_id: pageId,
    page_name: pageName,
    page_url: pageUrl
  })
}

/** 异步拿到用户信息后调用，释放被 BLOCK 的上报队列 */
export function setAplusUser(userId: string | number) {
  pushAplus('aplus.setMetaInfo', '_hold', 'BLOCK')
  pushAplus('aplus.setMetaInfo', '_user_id', userId)
  pushAplus('aplus.setMetaInfo', '_hold', 'START')
}
```

## 路由钩子与数据脱敏

建议在 Vue Router 的 `afterEach`（路由与页面标题均已确定）触发上报：

```ts [router/index.ts]
router.afterEach((to) => {
  const pageId = String(to.name || to.path.replace(/^\//, '') || 'home').toUpperCase()
  const pageName = String(to.meta.title || pageId)
  // 仅保留路径，避免 query 中夹带 token、ticket 等敏感参数
  trackPageView(pageId, pageName, to.path)
})
```

## 排查要点

- **PV 重复上报**：核对是否同时启用了 SDK 自动采集与手动 `sendPV`，确认 `aplus-waiting` 已设为 `'MAN'`。
- **路由切换缺上报或标题错误**：确认在路由解析完成且 `meta.title` 更新后再调用 `trackPageView`，不要放在重定向前的守卫中。
- **后台归属错误或无用户维度**：检查 `sapp_id`/`sapp_name` 是否与环境一致，并确认登录后调用过 `setAplusUser` 的 `START` 释放队列。
