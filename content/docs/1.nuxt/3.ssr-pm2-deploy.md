## 架构与前置要点

- **运行方式**：宿主机通过 PM2 集群托管 `node .output/server/index.mjs`，监听 `0.0.0.0:3000`（由 `NITRO_HOST` 与 `NITRO_PORT` 指定），Docker 中的 Nginx 通过 `host.docker.internal` 反代到宿主机端口。
- **Cloudflare 避坑**：若前置 Cloudflare，务必在 Speed / Scrape Shield 中关闭 **Rocket Loader**、**Mirage** 和 **Email Obfuscation**，否则注入脚本会破坏 SSR 水合。

## Docker Nginx 反代宿主机

在 Nginx 容器的 `docker-compose.yml` 中添加 `extra_hosts` 映射宿主机网关（完整 Nginx Compose 配置见 [Docker Nginx 反向代理](/docs/deployment/docker)）：

```yaml [docker-compose.yml]
services:
  nginx:
    extra_hosts:
      - "host.docker.internal:host-gateway"
```

在站点配置中反代至宿主机 `3000` 端口：

```nginx [default.conf]
location / {
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_pass http://host.docker.internal:3000;
}
```

## PM2 集群配置与自启

在项目根目录创建 `ecosystem.config.cjs`：

```js [ecosystem.config.cjs]
module.exports = {
  apps: [
    {
      name: 'nuxt-app',
      script: './.output/server/index.mjs',
      exec_mode: 'cluster',
      instances: 'max',
      env: {
        HOST: '0.0.0.0',
        PORT: '3000',
        NITRO_HOST: '0.0.0.0',
        NITRO_PORT: '3000'
      },
      max_memory_restart: '512M',
      out_file: './.pm2/out.log',
      error_file: './.pm2/error.log',
      time: true
    }
  ]
}
```

首次启动并持久化开机自启：

```sh [sh]
pm2 start ecosystem.config.cjs
pm2 save
pm2 startup
```

::note
`pm2 startup` 在 root 下直接生效；普通用户运行后，需复制并执行终端输出的完整 `sudo env PATH=...` 命令。之后每次新增或移除进程，都要重新 `pm2 save`。
::

## 非交互 SSH 部署避坑

通过 CI + SSH 自动发布 `.output` 并重载 PM2 时，注意两个常见坑：

1. **非交互 Shell 找不到 `pm2`**：SSH 远程执行命令默认不加载 `~/.zshrc` 或 fnm/nvm 初始化脚本，需显式探测 `npm config get prefix` 或 `~/.local/share/fnm/node-versions/*/installation/bin` 拼入 `PATH`。
2. **无缝重载区分首次启动**：通过 `pm2 describe <name>` 判断进程是否已存在——已存在时执行 `pm2 reload <name> --update-env` 实现零停机更新，首次部署则执行 `pm2 start ecosystem.config.cjs && pm2 save`。

## 验证

```sh [sh]
# 在 Nginx 容器内测试宿主机 SSR 端口连通性（应返回 200）
docker exec nginx curl -I http://host.docker.internal:3000
```

若页面异常，分别排查 `pm2 logs` 与 Nginx error log；若项目包含 `better-sqlite3` 等原生模块，需确保构建机与目标宿主机架构及 Node ABI 一致。
