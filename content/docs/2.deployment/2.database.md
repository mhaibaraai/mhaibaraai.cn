## 本地监听 Compose 配置

端口绑定 `127.0.0.1` 防止数据库暴露到公网；客户端远程管理时，通过 SSH 隧道连接服务器上的 `127.0.0.1:5432` 或 `127.0.0.1:6379`。

```yaml [~/database/docker-compose.yml]
services:
  postgres:
    image: postgres:16-alpine
    container_name: postgres
    restart: always
    ports:
      - "127.0.0.1:5432:5432"
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: your_postgres_password
      POSTGRES_DB: app
      TZ: Asia/Shanghai
    volumes:
      - postgres_data:/var/lib/postgresql/data

  redis:
    image: redis:7-alpine
    container_name: redis
    restart: always
    ports:
      - "127.0.0.1:6379:6379"
    command: redis-server --requirepass your_redis_password
    volumes:
      - redis_data:/data

volumes:
  postgres_data:
  redis_data:
```

启动与连通性验证：

```sh [sh]
docker compose up -d
docker exec postgres psql -U postgres -c "SELECT version();"
docker exec redis redis-cli -a 'your_redis_password' ping
```

## PostgreSQL 备份与恢复

::warning
重定向导出备份时**不要加 `-it`（特别是 `-t`）**：分配伪终端在 cron 等非交互环境中会直接失败，还可能在输出中混入 `\r` 损坏 SQL 文件。恢复传入标准输入时仅用 `-i`。
::

```sh [sh]
# 导出与压缩备份（不加 -it）
docker exec postgres pg_dump -U postgres -d app > backup.sql
docker exec postgres pg_dump -U postgres -d app | gzip > backup.sql.gz

# 从 SQL 或压缩包恢复（仅用 -i）
cat backup.sql | docker exec -i postgres psql -U postgres -d app
gunzip -c backup.sql.gz | docker exec -i postgres psql -U postgres -d app
```

### 启用 PostGIS 扩展

将 `postgres` 镜像替换为 PostGIS 版本，重建后在目标库执行建扩展语句：

```yaml [docker-compose.yml]
services:
  postgres:
    image: postgis/postgis:16-3.4-alpine
```

```sh [sh]
docker compose up -d postgres
docker exec postgres psql -U postgres -d app -c "CREATE EXTENSION IF NOT EXISTS postgis;"
```

## Redis AOF 持久化配置

Redis 默认仅开启 RDB 快照，如需 AOF 与内存淘汰策略，挂载自定义配置文件：

```conf [~/database/redis-conf/redis.conf]
appendonly yes
appendfsync everysec
save 900 1
save 300 10
save 60 10000
maxmemory 256mb
maxmemory-policy allkeys-lru
```

```yaml [docker-compose.yml]
services:
  redis:
    image: redis:7-alpine
    container_name: redis
    restart: always
    ports:
      - "127.0.0.1:6379:6379"
    command: redis-server /usr/local/etc/redis/redis.conf --requirepass your_redis_password
    volumes:
      - redis_data:/data
      - ./redis-conf/redis.conf:/usr/local/etc/redis/redis.conf:ro
```
