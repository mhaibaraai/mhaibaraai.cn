## 方案对比

| 方案 | 速度 | 稳定性 | 成本 | 复杂度 |
|---|---|---|---|---|
| 直连 GHCR | 慢 / 超时 | 差 | 无 | 无 |
| 同步到腾讯云 TCR | 最快（内网） | 最高 | 免费个人版 | 中 |
| Mihomo 代理 | 较快 | 中 | 需代理节点 | 低 |

## 方案一：同步到腾讯云 TCR

CI 构建完成后同时推送到 GHCR 和腾讯云 TCR，服务器直接从 TCR 内网拉取。

::steps{level="3"}

### 添加 Secrets

在仓库 **Settings → Secrets** 中配置：

- `TCR_REGISTRY`：`ccr.ccs.tencentyun.com`
- `TCR_NAMESPACE`：TCR 命名空间
- `TCR_USERNAME` / `TCR_PASSWORD`：腾讯云账号 ID 与访问凭证密码
- `PROD_SSH_HOST` / `PROD_SSH_USER` / `PROD_SSH_KEY`：生产服务器 SSH 登录信息

### 配置双仓库推送工作流

利用 `docker/metadata-action` 一次构建同时推送两个仓库：

::code-collapse

```yaml [.github/workflows/build.yml]
name: Build & Deploy

on:
  push:
    branches: [main]
  workflow_dispatch:

env:
  REGISTRY: ghcr.io
  IMAGE_NAME: ${{ github.repository }}
  TCR_IMAGE: ${{ secrets.TCR_REGISTRY }}/${{ secrets.TCR_NAMESPACE }}/<app-name>

permissions:
  contents: read
  packages: write

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v6
      - uses: docker/setup-buildx-action@v4

      - uses: docker/login-action@v4
        with:
          registry: ${{ env.REGISTRY }}
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}

      - uses: docker/login-action@v4
        with:
          registry: ${{ secrets.TCR_REGISTRY }}
          username: ${{ secrets.TCR_USERNAME }}
          password: ${{ secrets.TCR_PASSWORD }}

      - id: meta
        uses: docker/metadata-action@v5
        with:
          images: |
            ${{ env.REGISTRY }}/${{ env.IMAGE_NAME }}
            ${{ env.TCR_IMAGE }}
          tags: |
            type=sha,prefix=
            type=raw,value=latest,enable={{is_default_branch}}

      - uses: docker/build-push-action@v7
        with:
          context: .
          push: true
          tags: ${{ steps.meta.outputs.tags }}
          labels: ${{ steps.meta.outputs.labels }}
          cache-from: type=gha
          cache-to: type=gha,mode=max

  deploy:
    needs: build
    runs-on: ubuntu-latest
    steps:
      - uses: appleboy/ssh-action@v1
        with:
          host: ${{ secrets.PROD_SSH_HOST }}
          username: ${{ secrets.PROD_SSH_USER }}
          key: ${{ secrets.PROD_SSH_KEY }}
          port: ${{ vars.PROD_SSH_PORT || 22 }}
          script: |
            cd ~/apps/<app-name>
            docker compose pull
            docker compose up -d
            docker image prune -f
```

::

### 服务器登录 TCR 并拉取

```sh [sh]
docker login ccr.ccs.tencentyun.com -u <TCR_USERNAME> -p <TCR_PASSWORD>
```

对应修改 `docker-compose.yml` 中的 `image: ccr.ccs.tencentyun.com/<namespace>/<app-name>:latest`。

::

## 方案二：Mihomo 代理

在服务器上运行 Mihomo（Clash Meta 内核），让 Docker daemon 走本地代理拉取 GHCR 镜像。

::steps{level="3"}

### 下载匹配 CPU 指令集的版本

```sh [sh]
# 有 avx2 -> v3，有 sse4_2 -> v2，都没有 -> compatible
grep -m1 flags /proc/cpuinfo | grep -o 'avx2\|sse4_2'

wget https://github.com/MetaCubeX/mihomo/releases/download/v1.19.20/mihomo-linux-amd64-compatible-v1.19.20.gz
gzip -d mihomo-linux-amd64-compatible-v1.19.20.gz
sudo install -m 755 mihomo-linux-amd64-compatible-v1.19.20 /usr/local/bin/mihomo
```

### 本地拉取订阅并上传

大多数订阅服务会拦截云服务器 IP 的直接请求，建议在**本地**下载 Clash 配置后再 `scp` 上传：

```sh [sh]
# 本地下载并上传
curl -o config.yaml "https://你的订阅链接" -H "User-Agent: clash-verge/v2.0.0"
scp -P <端口> config.yaml ubuntu@<服务器IP>:/tmp/config.yaml

# 服务器放置配置并查看实际监听的 mixed-port（下文以 7893 为例）
sudo mkdir -p /etc/mihomo
sudo mv /tmp/config.yaml /etc/mihomo/config.yaml
sudo chmod 600 /etc/mihomo/config.yaml
```

### 配置 systemd 与 Docker daemon 代理

```sh [sh]
sudo tee /etc/systemd/system/mihomo.service << 'EOF'
[Unit]
Description=Mihomo Proxy
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/mihomo -d /etc/mihomo
Restart=on-failure
RestartSec=5s

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload && sudo systemctl enable --now mihomo

sudo mkdir -p /etc/systemd/system/docker.service.d
sudo tee /etc/systemd/system/docker.service.d/http-proxy.conf << 'EOF'
[Service]
Environment="HTTP_PROXY=http://127.0.0.1:7893"
Environment="HTTPS_PROXY=http://127.0.0.1:7893"
Environment="NO_PROXY=localhost,127.0.0.1,ccr.ccs.tencentyun.com"
EOF

sudo systemctl daemon-reload && sudo systemctl restart docker
```

### 验证连通性

```sh [sh]
curl -x http://127.0.0.1:7893 https://www.google.com -I
docker pull ghcr.io/<username>/<image>:latest
```

::

::tip
以后更新订阅时，沿用本地 `curl` + `scp` 覆盖 `/etc/mihomo/config.yaml` 后执行 `sudo systemctl restart mihomo` 即可。
::
