## Claude Code

```json [~/.claude/settings.json]
{
  "attribution": {
    "commit": "",
    "pr": ""
  },
  "statusLine": {
    "type": "command",
    "command": "bun x ccusage statusline --cost-source cc --no-offline",
    "padding": 0
  }
}
```

::tip
`attribution` 置空后，Claude Code 生成的提交与 PR 不再附带署名。
::

## MCP Servers

::code-collapse

```json [mcp-servers.json]
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "YOUR_TOKEN" }
    },
    "context7": {
      "type": "http",
      "url": "https://mcp.context7.com/mcp",
      "headers": { "CONTEXT7_API_KEY": "YOUR_KEY" }
    },
    "sequential-thinking": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-sequential-thinking"]
    },
    "cloudflare-docs": {
      "type": "http",
      "url": "https://docs.mcp.cloudflare.com/mcp"
    }
  }
}
```

::

::note
启用的 MCP 建议控制在 10 个以内，避免占用过多上下文窗口。
::
