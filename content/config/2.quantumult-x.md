## 一键导入

下面的「一键添加规则集」会把三份规则集同时添加到 Quantumult X 的「分流 → 引用」中，并设置好策略。完整配置模板可在「配置文件 → 下载」中通过模板地址导入。

::proxy-import{client="quantumult-x"}
::

::warning
模板中的 `YOUR_SUBSCRIPTION_URL` 是占位符，请在 `[server_remote]` 中替换为你自己的订阅地址。规则集里引用的 `AI`、`Proxy` 策略需要先在 `[policy]` 中定义。
::

## 策略组

```ini [template.conf]
[policy]
static=Proxy, Auto, HK, JP, US, direct
url-latency-benchmark=Auto, server-tag-regex=.*, check-interval=600, tolerance=50
url-latency-benchmark=HK, server-tag-regex=(?i)港|HK|Hong, check-interval=600, tolerance=50
static=AI, US, JP, Proxy
static=Final, Proxy, direct
```

## 规则集

与 Surge 共用同一份规则源，站点自动转换为 Quantumult X 语法（`HOST-SUFFIX`、`IP6-CIDR` 等）。

::rule-set-table{client="quantumult-x"}
::

```ini
[filter_remote]
https://mhaibaraai.cn/proxy/rules/quantumult-x/ai.list, tag=AI, force-policy=AI, update-interval=86400, opt-parser=false, enabled=true
https://mhaibaraai.cn/proxy/rules/quantumult-x/dev.list, tag=Dev, force-policy=Proxy, update-interval=86400, opt-parser=false, enabled=true
https://mhaibaraai.cn/proxy/rules/quantumult-x/direct.list, tag=Direct, force-policy=direct, update-interval=86400, opt-parser=false, enabled=true
```
