## 一键导入

::proxy-import{client="surge"}
::

::warning
模板中的 `YOUR_SUBSCRIPTION_URL` 是占位符。导入后在 Surge 中编辑配置，替换为你自己的机场订阅地址，否则所有代理分组都是空的。
::

## 设计思路

::steps{level="3"}
### 订阅只出现一次

用一个隐藏的 `Subscription` 分组承载 `policy-path`，其余分组通过 `include-other-group` 复用节点，更换机场只需改一行。

### 按地区自动测速

`HK`、`JP`、`US` 用 `policy-regex-filter` 从订阅中筛选节点，`url-test` 每 10 分钟测速并自动选择最快节点。

### AI 服务单独分流

Claude、ChatGPT 等服务对地区较敏感，单独放进 `AI` 分组，默认优先美国节点。

### 兜底策略

`GEOIP,CN` 直连，其余流量走 `Final`，DNS 解析失败时也走 `Final`。
::

## 代理分组

```ini [template.conf]
[Proxy Group]
Subscription = select, policy-path=YOUR_SUBSCRIPTION_URL, update-interval=86400, hidden=true
Proxy = select, Auto, HK, JP, US, DIRECT
Auto = url-test, include-other-group=Subscription, interval=600, tolerance=50
HK = url-test, include-other-group=Subscription, policy-regex-filter=(?i)港|HK|Hong, interval=600, tolerance=50
AI = select, US, JP, Proxy
Final = select, Proxy, DIRECT
```

## 规则集

规则集以 Surge 语法为单一来源维护，站点同时输出 Quantumult X 版本。

::rule-set-table{client="surge"}
::

```ini
[Rule]
RULE-SET,https://mhaibaraai.cn/proxy/rules/surge/ai.list,AI
RULE-SET,https://mhaibaraai.cn/proxy/rules/surge/dev.list,Proxy
RULE-SET,https://mhaibaraai.cn/proxy/rules/surge/direct.list,DIRECT
RULE-SET,LAN,DIRECT
GEOIP,CN,DIRECT
FINAL,Final,dns-failed
```

::note
仓库提交前会运行 `pnpm check:proxy` 扫描 `public/proxy` 与规则源，发现节点定义、订阅链接、UUID 或密码参数即拒绝，避免误把私有配置公开。
::
